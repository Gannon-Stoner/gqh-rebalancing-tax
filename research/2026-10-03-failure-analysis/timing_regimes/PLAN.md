# Timing and regime analysis: exploratory family fixed before computation

This analysis uses only data dated through 2024-10-01. No OOS read, unlock,
download, model selection, or alteration of frozen files is authorized here.
Existing full-sample findings have already been seen; this is exploratory.

Seven economic decompositions will all be reported: the baseline L-4 to F1
spread, L-4 to L spread, L-1 to L spread, L to F1 spread, ES-only L-4 to F1,
ZN-only L-4 to F1, and an unfiltered midmonth L-13 to L-8 spread control.
All use the original decision-date quantities and 1x/2x registered leg costs;
the midmonth control has its own original pseudo-event signal and sizing.
Shorter windows are not relevered to equalize risk. Leg-only rows retain the
original number of contracts, allowing dollar attribution rather than an
optimized new portfolio. The two leg rows are exact net P&L decompositions.

Report full IS, the registered common evaluation period, fixed calendar eras,
quarter/nonquarter, and long/short directions. Report yearly P&L, concentration,
leave-one-year-out Sharpe, three-month-block uncertainty, and all failed rows.
Compare actual L-5 signal held-contract paths with the earlier L-12 sign figure;
pre-L-5 paths conditioned on L-5 sign are descriptive, not implementable signals.
No significance claim will be made without acknowledging this exploratory family
and prior searches. Existing IS chronological splits are stability checks, not a
new untouched holdout.
